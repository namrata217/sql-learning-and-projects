# Employee Management System

## 📌 Project Overview

The Employee Management System is a hands-on MySQL project created to practice SQL concepts using a real-world employee database scenario.

The project is being developed step by step while learning SQL.

---

## 🎯 Project Objective

The objective of this project is to design an employee database and perform different operations such as:

* Adding employees
* Viewing employee records
* Searching employees
* Updating employee information
* Deleting employee records
* Filtering employees
* Analyzing employees by department
* Performing salary-related analysis

---

## 🛠️ Technology

* **Database:** MySQL 8.0
* **Language:** SQL

---
